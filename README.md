# GSAP Animation Lab

An interactive motion design playground exploring web animation, creative coding and modern motion experiences using GSAP.

**Created by Kunal Bhiwania**

## Live Demo

[View Live Website](https://kunalbhiwanias.github.io/gsap-animation-lab/)

## Project Overview

This project explores the intersection of graphic design, motion graphics and frontend development through interactive web animations.

## Features

- Animated hero typography
- GSAP-powered entrance animations
- Scroll-triggered animations using ScrollTrigger
- Staggered card transitions
- Interactive hover effects
- Responsive layout for mobile and desktop
- GSAP timeline and animation experiments

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP 3
- GSAP ScrollTrigger
